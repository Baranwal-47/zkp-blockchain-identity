| Boundary | Description |
|----------|-------------|
| deployer secrets -> Sepolia chain | The funded `PRIVATE_KEY`/RPC are gitignored secrets that must never enter a tracked file or worktree; misuse spends real funds or leaks the key |
| new verifier address -> consuming backend | The backend must point at the just-deployed verifier; a stale `.env` or hardcoded fallback silently breaks on-chain verification |
| zk-proofs build artifacts -> backend runtime | The copied wasm/zkey/vkey must be the new frozen circuit, not the superseded flat-Poseidon(5) ones |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
