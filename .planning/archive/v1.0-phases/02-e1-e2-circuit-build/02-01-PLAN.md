## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| prover (private witness) -> public signals | A malicious prover controls all private inputs (attr[], salt[]) and can attempt to publish predicates/disclosures inconsistent with the committed root |
| build toolchain -> compiled artifacts | The circom2 compiler + vendored circomlib produce the r1cs/wasm that Phase 3 trusts irreversibly (DESIGN-ONCE) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | dob/programmeLevel double-supply | mitigate | Reuse the SAME attr[2] and attr[3] private signals for both the leaf hash and the predicate, so a prover cannot commit one DOB/level and prove a predicate on another |
| T-02-02 | Information disclosure | revealedValue[i] leaking a hidden attr | mitigate | Circuit-enforced `(1 - revealMask[i]) * revealedValue[i] === 0` forces hidden values to publish as 0 (CIRC-03 strong option) |
| T-02-03 | Spoofing / Replay | nonce optimized out of constraint system | mitigate | `nonceSq <== nonce * nonce` forces nonce into a real constraint (REPL-01); replay-against-different-nonce verified in plan 02-02 (REPL-02) |
| T-02-04 | Tampering | wrong zero-pad leaf value via transcription error | mitigate | leaf 7 computed by an actual `Poseidon(2)(0,0)` component, not a hardcoded 77-digit constant |
| T-02-05 | Information disclosure | field underflow in currentDateInt - 180000 | accept | currentDateInt is set by the trusted backend to a real ~20XXXXXX date; underflow is unreachable in practice. Documented in-circuit |
| T-02-SC | Tampering | npm/circom toolchain installs | accept | No new packages installed this phase; circom2/snarkjs/circomlib already vendored and present (RESEARCH section 2). No Package Legitimacy Gate needed |
