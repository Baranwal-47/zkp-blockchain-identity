|----------|-------------|
| caller → POST /verify, /verify-onchain | Untrusted proof + publicSignals + sessionId; cryptographic verify + nonce enforcement gate acceptance |
| backend → Sepolia (read-only) | View calls to IdentityVerifier.verifyProof and CredentialRegistry.getCredentialByHash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Replay | captured proof QR re-submitted to a new session | mitigate | validateAndConsume enforces nonce match + freshness (Date.now() server clock) + one-time-use; consumed on first valid use (REPL-03) |
| T-04-07 | Tampering | client clock used for freshness | mitigate | Expiry compared against server Date.now() only; no client timestamp is trusted (RESEARCH anti-pattern "client clocks") |
| T-04-08 | Denial of Service | nonce burned by a bogus proof to grief a session | mitigate | Nonce consumed only after the cryptographic proof verifies; an invalid proof returns invalid_proof without consuming the nonce |
| T-04-09 | Spoofing | missing env → dead contract address silently used | mitigate | Stale hardcoded fallbacks removed; missing VERIFIER_ADDRESS/REGISTRY_ADDRESS throws at startup (fail loud) |
</threat_model>
