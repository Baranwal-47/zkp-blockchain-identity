<objective>
Add the shared `timed(label, fn)` timing helper (blueprint §10.1) and route every one of the six measured E1+E2 crypto operations through it, so each op prints elapsed seconds in one consistent format. This replaces the existing ad-hoc `console.time`/`console.timeEnd` instrumentation (which prints raw ms and cannot be aggregated) and adds new timing for the two nonce operations that have none today.

Purpose: PERF-01 requires every new crypto op to print elapsed seconds "via the shared timing helper". The five existing call sites print raw ms, and nonce issue/check are untimed — neither satisfies the requirement as written. This plan establishes the single instrumentation path that Plan 02's `bench.js` drives.

Output: `zkp-backend/utils/timing.js`, `privdId_admin/backend/utils/timing.js`, and migrated call sites in `server.js` and `identityCommitment.js`.
</objective>

Canonical helper behavior (blueprint §10.1):
- Signature: `timed(label, fn)` — async; awaits fn().
- Returns: `{ out, seconds }` where `out` is fn()'s return value and `seconds` is the elapsed (performance.now() delta) / 1000.
- Side effect: `console.log("[perf] " + label + ": " + seconds.toFixed(3) + " s")`.

Existing call sites in zkp-backend/server.js (CommonJS):
- ProofGeneration wraps `await snarkjs.groth16.fullProve(input, wasmPath, zkeyPath)` (currently console.time/timeEnd around it).
- OffChainVerification wraps `await snarkjs.groth16.verify(vKey, publicSignals, proof)`.
- OnChainVerification wraps `await verifierContract.verifyProof(pA, pB, pC, publicSignals)`.
- Nonce issue: `issueNonce()` is called in the POST /session/nonce handler (synchronous, no timing today).
- Nonce check: `validateAndConsume(sessionId, publicSignals[1])` is called in both /verify and /verify-onchain (synchronous, no timing today).

Existing call site in privdId_admin/backend/utils/identityCommitment.js (ESM):
- computeMerkleRoot has console.time("computeMerkleRoot") / console.timeEnd("computeMerkleRoot") around its body; the function is `export async function computeMerkleRoot(attrs, salts)`.
</interfaces>
