<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external ptau host -> local ceremony | The downloaded `.ptau` is an untrusted large binary fetched over the network; a wrong/corrupt/too-small file silently corrupts the setup |
| contributor entropy -> final zkey | Each `zkey contribute` mixes secret randomness; retained "toxic waste" weakens soundness |
| frozen r1cs -> deployed verifier | The exported Solidity verifier is trusted irreversibly on-chain; a mismatch against the frozen circuit causes silent verification failure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | stale/wrong ptau silently producing a zkey that doesn't match the circuit | mitigate | `snarkjs zkey verify build/identity.r1cs <pot14> identity_final.zkey` is a mandatory STOP gate (SETUP-01); ptau size sanity-checked > 1 MB and power (2^14) chosen for the frozen 7825 count |
| T-03-02 | Tampering | toxic-waste retention by a single contributor | mitigate | 3-contributor chain + final `zkey beacon` with a public block hash no single party controls; entropy sourced from /dev/urandom and never persisted |
| T-03-03 | Tampering / Repudiation | predictable/weak beacon value chosen by deployer | mitigate | Beacon uses a real, externally-verifiable recent block hash; the hash + block number recorded in CEREMONY_LOG.md for paper reproducibility |
| T-03-04 | Information disclosure | raw entropy strings leaked into a tracked file / SUMMARY | mitigate | Only the entropy SOURCE is recorded; raw values never written to any file (RESEARCH Security Domain V6) |
| T-03-05 | Tampering | exported verifier compiled against wrong/old zkey | mitigate | Export commands read identity_final.zkey directly; `grep contract Groth16Verifier` + `npx hardhat compile` confirm the exported file is the new one before any deploy |
| T-03-SC | Tampering | npm/ptau supply chain | accept | No new npm packages (snarkjs/circom2/hardhat already vendored, RESEARCH Package Legitimacy Audit "not applicable"); the only fetched artifact is the ptau, gated by mirror-fallback + size sanity check, not a registry-package install |
</threat_model>
